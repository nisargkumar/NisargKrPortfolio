# Where each cube face sends the visitor.
#
# A project can have up to two destinations:
#
#   <slug>.case = https://...   ->  "View case study"   button
#   <slug>.live = https://...   ->  "See live website"  button
#
# A bare "<slug> = <url>" is treated as the case study. The buttons appear
# under the cube for whichever project is facing you, and the face itself
# opens the case study (or the live site if there is no case study).
#
# Use "soon" instead of a URL for a project that has shipped but has no public
# site yet — it renders as a disabled "Live website - coming soon" button:
#
#   <slug>.live = soon
#
# Fill in what you have and leave the rest commented out — a project with no
# links stays inert and keeps showing its [LINK] token, rather than going
# somewhere wrong. Then run:  python3 build.py
#
# Links open in a new tab.
